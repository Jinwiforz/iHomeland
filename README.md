# iHomeland

iHomeland 是一款面向 PC 的开放世界在线动作角色扮演游戏。项目目标是构建可探索、可战斗、可生活、可持续演化并能够稳定运营的在线世界。

## 产品方向

目标产品中，每名玩家平时生活在属于自己的持久世界，在其中探索、经历故事和建设家园；玩家可以邀请其他人进入自己的世界，也可以前往所有玩家共同活动的公开世界。

### 世界组织

- **个人世界**：玩家默认进入自己的世界，能够独立体验探索、剧情、战斗、生活和家园内容。世界保存玩家造成的变化，并围绕玩家自己的经历持续发展。
- **邀请访问**：个人世界的主人可以邀请其他玩家进入。访客能够共同探索、战斗、解谜、采集和建设；哪些行为可以改变世界由主人和具体玩法决定。
- **公开世界**：玩家可以主动进入共享区域，与陌生玩家相遇，参与动态事件、合作挑战、竞技、交易、组织和大型社会活动。

玩家身份和个人成长在三种体验间保持连续。离开邀请访问或公开世界后，玩家可以回到自己的个人世界继续独立游玩。

核心体验包括：

- **自由探索**：通过步行、骑乘、攀爬和轻功式移动发现城镇、荒野、遗迹、地下空间、人物与隐藏故事。
- **多种解法**：面对事件和关卡时，可以选择正面战斗、潜行、交涉、观察环境、解谜、交易或利用世界机制。
- **动作战斗**：自由组合武器、招式与特殊能力，通过攻击、防御、闪避、反制、位置和资源管理形成不同战斗风格，不使用固定职业限制角色成长。
- **鲜活世界**：NPC 拥有身份、关系、活动与需求；故事通过人物、场景、物品和玩家行为共同呈现，世界会对选择产生可观察的反馈。
- **个人家园**：玩家能够收集资源、建造和布置空间、发展设施、邀请伙伴协助经营，并让家园反映自己的冒险成果。
- **生活与身份**：采集、制作、烹饪、医疗、表演、交易和休闲活动既能独立游玩，也能与探索、人物关系和世界事件相互作用。
- **自主联机**：邀请访问适合熟人共同冒险，公开世界承载偶遇、组队、竞技和社区关系；个人世界始终提供完整的独立体验。
- **长期成长**：成长来自能力学习、装备与资源、人物关系、家园建设、世界发现和玩家技巧，不依赖单一数值路线。

主要游戏循环：

```text
探索世界
  -> 发现人物、线索、危险与机会
  -> 选择自己的解决方式
  -> 获得能力、资源、关系与故事结果
  -> 发展角色和个人家园
  -> 邀请访客、前往公开世界或继续独自冒险
```

## 商业品质目标

每个产品里程碑会逐步提高玩法完整度、内容品质、性能、稳定性、安全、可访问性、平台兼容、可观测性和运营能力。复杂技术只有在当前行为、质量目标和问题证据同时成立时才进入正式产品。
