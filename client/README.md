# iHomeland Unity Client

`client/` 是 Unity PC 客户端入口。`qualify-server-v1` 完成前，本目录只保留版本入口与本文档，不创建 Unity runtime、scene、prefab 或 generated protocol。

服务端资格验收完成后，客户端按 `docs/roadmap.md` 实现；服务端交付物与接入验收由 `docs/client-integration.md` 定义，运行时与 UI 规则分别由客户端架构文档定义。
